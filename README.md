# iPAS AI 應用規劃師刷題工具

- 範圍：115 年（2026）iPAS AI 應用規劃師初級＋中級
- 自編練習題：171 題
- 初級：L11、L12
- 中級：L21 + L22/L23
- 功能：刷題、即時詳解、正式模擬、倒數計時、錯題本、弱點分析、localStorage 進度保存
- 官方考古題：14 份公告試題，於「考古題」分頁直接點「開始刷題」，無須手動匯入 PDF
- 官方考古題首次開卷時會自動讀取 iPAS 官方公告試題來源並快取於瀏覽器，後續可直接繼續作答
- GitHub Pages：將 `index.html` 放在 repository 根目錄即可

注意：
- 「刷題練習／正式模擬」為依官方評鑑範圍自編的練習題。
- 「考古題」分頁使用 iPAS 官方公告試題來源；若題目包含圖表或程式碼圖片，請以「查看官方 PDF」核對原題。
- 因瀏覽器跨站讀取政策不同，建議部署於 GitHub Pages 後使用；工具內建多重讀取備援與本機快取。
